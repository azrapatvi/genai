# Email Sending Agent

An AI agent that sends an email only after you say **yes**.

## File
| File | What it does |
|---|---|
| `email_sending.ipynb` | First sends a plain test email, then builds an agent that asks permission before sending |

## Notes
- Add `SENDER_EMAIL` and `GMAIL_APP_PASSWORD` to a `.env` file.
- Use a Gmail **App Password**, not your normal password.
- Add `GROQ_API_KEY` too.
