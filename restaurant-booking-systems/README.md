# Restaurant Booking Agent

An agent that books restaurant tables using a SQLite database. A human must approve the final booking.

## Details
- 5 tables: `table-1` to `table-5`
- Tools: book a table, check availability, view bookings
- Double booking is blocked

## File
| File | What it does |
|---|---|
| `restaurant-booking-system.ipynb` | The whole agent |
