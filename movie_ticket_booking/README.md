# Movie Ticket Booking Agent

A friendly agent that books movie tickets. You must approve before the booking is final.

## Details
- 3 shows: 10 AM, 12 PM and 2 PM
- 20 seats in each show
- Tools: check slots, book a slot, show bookings

## File
| File | What it does |
|---|---|
| `movie_booking.ipynb` | The whole agent |

## Notes
- Bookings are kept in memory only. They are lost when you close the notebook.
- Add `GROQ_API_KEY` to a `.env` file.
